# Scoundrelatro

Scoundrel's dungeon crawl, scored like a Balatro poker hand, with Darkest Dungeon's stress and light.

## Download

Get the latest build from **[Releases](https://github.com/uilianks/scoundrelatro-releases/releases/latest)**.

- **Windows:** download the `-windows.zip`, unzip it and run `Scoundrelatro.exe`. The build is unsigned, so if SmartScreen warns, click *More info → Run anyway*.
- **Linux:** download the `-linux.tar.gz`, extract it and run `./Scoundrelatro.x86_64`.

The game opens fullscreen at your screen resolution; change this under Options. It's available in Portuguese (pt-BR) and English.

This repository only hosts the playable builds.
